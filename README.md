# 🧭 CompassFocus

**التركيز الذكي باستخدام تقنيات بومودورو**

تطبيق ويب متقدم يساعد الطلاب والمهنيين على تحسين إنتاجيتهم من خلال تقنية بومودورو المشهورة مع واجهة احترافية وميزات ذكية.

## ✨ الميزات الرئيسية

### ⏱️ مؤقت ذكي
- عد تنازلي دقيق بصيغة MM:SS
- تحديث فوري كل ثانية
- حلقة دوارة توضح التقدم

### 🎯 مدد زمنية مرنة
- **25 دقيقة** - جلسة عمل قياسية
- **15 دقيقة** - جلسة عمل قصيرة
- **5 دقائق** - استراحة سريعة
- **45 دقيقة** - جلسة عمل طويلة
- **10 دقائق** - استراحة عادية
- **30 دقيقة** - جلسة عمل معمقة

### 🎮 التحكم الكامل
- ▶️ **ابدأ الجلسة** - بدء العد التنازلي
- ⏸️ **إيقاف مؤقت** - إيقاف الجلسة مؤقتاً
- ⏹️ **إيقاف** - إنهاء الجلسة
- ↻ **إعادة تعيين** - إرجاع الوقت للقيمة الأساسية

### 🔊 تنبيهات صوتية
- 🔇 بدون صوت
- 🔔 إشعار
- 🎵 رنة لطيفة
- 🔊 جرس عالي

### 📊 إحصائيات وتتبع
- ⭐ عدد الجلسات المكتملة
- 🏆 إجمالي الوقت المنتج
- 💾 حفظ البيانات تلقائياً (localStorage)

### 🎨 واجهة احترافية
- تصميم glassmorphism عصري
- دعم اللغة العربية RTL
- استجابة كاملة (Mobile, Tablet, Desktop)
- تأثيرات سلسة وانتقالات جميلة
- ألوان متناسقة وجذابة

### 🚨 تنبيهات ذكية
- تنبيه بدقيقة واحدة متبقية
- تحذير عند آخر 10 ثوانٍ
- رسائل تحفيزية عند الإكمال
- الانتقال التلقائي بين العمل والاستراحة

## 🚀 كيفية الاستخدام

### خطوات سريعة:

1. **افتح الملف** `index.html` في متصفحك المفضل
2. **اختر مدة زمنية** من الأزرار الستة
3. **حدد تنبيهاً صوتياً** من القائمة المنسدلة (اختياري)
4. **اضغط ▶️ ابدأ الجلسة** لبدء العد التنازلي
5. **استمتع بالتركيز** - التطبيق سيعلمك عند انتهاء الوقت
6. **خذ استراحة** - التطبيق ينقل تلقائياً لفترة استراحة

### تلميحات الاستخدام:
- ✅ استخدم 25 دقيقة للعمل المركز
- ✅ خذ 5 دقائق استراحة بعد كل جلسة
- ✅ بعد 4 جلسات، خذ استراحة أطول (15-30 دقيقة)
- ✅ الإحصائيات تُحفظ تلقائياً في متصفحك
